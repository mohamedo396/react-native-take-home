# React Native Code Quality Assessment

Welcome to the coding interview! This project contains a React Native/Expo application with intentional bad practices that you'll need to identify and fix.

## Objective

Review the `App.tsx` file and refactor it to follow React Native and TypeScript best practices. The code is intentionally written poorly to test your ability to:

- Identify common anti-patterns
- Apply TypeScript best practices
- Optimize React Native performance
- Write clean, maintainable code

## Getting Started

### Prerequisites
- Node.js installed
- npm or yarn
- Expo CLI (optional, will be installed automatically)

### Installation

```bash
npm install
```

### Running the App

```bash
npm start
```

Then:
- Press `i` for iOS simulator
- Press `a` for Android emulator
- Press `w` for web browser
- Or scan QR code with Expo Go app on your phone

## Your Task

1. **Review** the code in `App.tsx` (take 10-15 minutes)
2. **Identify** all bad practices you can find
3. **Refactor** the code to fix the issues (45-60 minutes)
4. **Be ready to discuss** your changes and reasoning

## What We're Looking For

- TypeScript proficiency
- Understanding of React hooks and lifecycle
- State management best practices
- Performance optimization knowledge
- Memory leak prevention
- Clean code principles

## Hints

The bad practices range from easy to advanced:
- **Easy**: Type safety, naming, styling
- **Medium**: State management, hooks, performance
- **Advanced**: Memory leaks, race conditions, async patterns

## Deliverables

When you're done:
1. Refactored `App.tsx` with your improvements
2. Be prepared to explain each change you made
3. Discuss any additional improvements you would suggest

## Notes

- The app should remain functional after your changes
- Focus on correctness first, then optimization
- Feel free to ask questions if anything is unclear

Good luck!
